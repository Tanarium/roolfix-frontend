# ROOLFiX — Public Website

## 1. Objetivo

Crear la página web pública y corporativa de **ROOLFiX**.

La web debe presentar la empresa de forma profesional, moderna y cercana, explicar claramente sus servicios y facilitar que un potencial cliente contacte con ROOLFiX.

La página será pública y estará orientada principalmente a potenciales clientes.

El dominio final será:

```text
https://roolfix.com
```

La aplicación interna de gestión de empleados es un proyecto independiente y **NO debe formar parte de este proyecto**.

La aplicación interna estará posteriormente disponible en:

```text
https://app.roolfix.com
```

---

# 2. Estado actual

El proyecto es un proyecto web independiente de la aplicación TimeTracker.

## Stack

- React
- TypeScript
- Vite
- CSS

El proyecto debe mantenerse sencillo y ligero.

No añadir dependencias innecesarias.

# 7. Hero

El Hero es la sección más importante de la página.

Debe comunicar inmediatamente:

1. Qué hace ROOLFiX.
2. Qué tipo de cliente atiende.
3. Por qué debería contactar.

No utilizar frases vacías o excesivamente corporativas.

Ejemplo conceptual:

```text
Cuidamos cada espacio como si fuera nuestro.

Servicios profesionales de limpieza,
mantenimiento y cuidado de instalaciones.

[ Solicitar presupuesto ]
[ Conocer nuestros servicios ]
```

El texto definitivo debe ser convincente y natural.

Utilizar una fotografía grande y profesional relacionada con los servicios de ROOLFiX.

Preferiblemente una fotografía real de un trabajo de la empresa.

# 8. Servicios

Crear una sección visual para presentar los principales servicios.

Los servicios exactos deberán ajustarse a los servicios reales de ROOLFiX.

Como punto de partida:

### Limpieza

Limpieza profesional y mantenimiento de espacios para garantizar instalaciones cuidadas y agradables.

### Limpiezas especiales

Limpiezas a fondo, post-construcción, reformas y trabajos puntuales.

### Mantenimiento

Mantenimiento general y resolución de necesidades habituales de las instalaciones.

### Comunidades

Servicios destinados a comunidades de propietarios y zonas comunes.

### Piscinas

Mantenimiento y cuidado de piscinas, si este servicio forma parte realmente de la oferta de ROOLFiX.

### Otros servicios

Permitir añadir posteriormente nuevos servicios sin tener que rediseñar la sección.

Cada servicio debería tener:

- Icono o imagen
- Título
- Descripción breve
- Posiblemente enlace/ancla para ampliar información

No inventar servicios que ROOLFiX no ofrezca realmente.

# 19. Rendimiento

La web debe ser rápida.

Prioridades:

- Optimizar imágenes.
- Utilizar formatos modernos cuando sea apropiado.
- Lazy loading para imágenes fuera del viewport.
- Evitar dependencias pesadas.
- Evitar animaciones excesivas.
- Minimizar JavaScript innecesario.

El Hero debe cargar rápidamente.

# 20. Accesibilidad

Cumplir buenas prácticas de accesibilidad:

- Contraste adecuado.
- Elementos interactivos accesibles.
- Navegación mediante teclado.
- Alt text.
- Labels en formularios.
- Estados de focus.
- HTML semántico.

No depender únicamente del color para transmitir información.

---

# 21. Animaciones

Utilizar animaciones sutiles.

Ejemplos:

- Fade-in al entrar en viewport.
- Hover en botones.
- Transiciones suaves.
- Aparición progresiva de tarjetas.

Evitar:

- Animaciones excesivas.
- Parallax agresivo.
- Efectos que distraigan.
- Animaciones que ralenticen la página.

La página debe sentirse premium pero profesional.
